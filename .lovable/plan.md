
# منصة SANAD — خطة البناء

منصة كبيرة بأربع واجهات. سأبنيها على **مراحل متتابعة** بدلاً من دفعة واحدة لضمان الجودة. هذه الخطة للمرحلة الأولى (الأساس + واجهة ولي الأمر)، وسنبني الباقي في الردود التالية.

## التقنيات
- **الواجهة:** TanStack Start + React + Tailwind v4 + shadcn/ui
- **الخلفية:** Lovable Cloud (قاعدة بيانات + مصادقة + تخزين ملفات)
- **اللغة:** عربية + إنجليزية مع دعم RTL/LTR (i18n)
- **الهوية:** بنفسجي/أزرق عصري (#6366F1, #A78BFA)
- **الخط:** Tajawal للعربية، Inter للإنجليزية

## المرحلة 1 — الأساس (هذا الرد)
1. تفعيل Lovable Cloud
2. نظام التصميم (ألوان، خطوط، RTL، الوضع الليلي)
3. صفحة الهبوط (Landing) لتعريف المنصة
4. نظام المصادقة (تسجيل/دخول) مع 4 أدوار: parent / specialist / teacher / admin
5. مخطط قاعدة البيانات الكامل:
   - `profiles` (المستخدمون)
   - `user_roles` + enum `app_role` + دالة `has_role`
   - `children` (الأطفال)
   - `parent_child` (ربط ولي الأمر بالطفل)
   - `diagnoses` (التشخيصات)
   - `reports` (التقارير)
   - `individual_plans` (الخطط الفردية)
   - `attendance` (الحضور)
   - `assignments` (الواجبات)
   - `grades` (النقاط)
   - `appointments` (المواعيد)
   - `messages` (الرسائل)
   - `notifications` (الإشعارات)
   - `notes` (الملاحظات السلوكية)
6. سياسات RLS لكل جدول حسب الدور
7. تخطيط محمي `_authenticated` يوجه لـ Dashboard حسب الدور
8. **واجهة ولي الأمر كاملة** بكل أقسامها (الرئيسية، ملف الطفل، التشخيص، التقدم، الحضور، الواجبات، المواعيد، الرسائل)
